# بوابة نعامة للصحة المدرسية — حزمة النشر

## المكونات
- صفحة عامة تضم التقويم والنشرات والإسعافات والمسابقات والشهادات.
- نموذج مشاركة نصية للطلاب، تُحفظ المشاركات في SQLite بحالة «بانتظار المراجعة».
- لوحة إدارة محمية بكلمة مرور لإجازة أو رفض المشاركات وإدارة إعلان عام.
- لا تُقبل صور الطلاب أو الإجازات المرضية في هذه المرحلة حماية للخصوصية.

## التشغيل محليًا
يتطلب Node.js **22.13 أو أحدث** (ويُفضل إصدار حديث يدعم `node:sqlite`). لا توجد حزم npm خارجية.

في PowerShell:
```powershell
$env:ADMIN_PASSWORD="استبدل-هذا-بكلمة-مرور-سرية-طويلة-وفريدة"
node server.js
```

على Linux/macOS:
```bash
ADMIN_PASSWORD='use-a-unique-long-secret-password' node server.js
```

افتح `http://localhost:3000` للموقع العام و`http://localhost:3000/login` للإدارة. لا تفتح `public/index.html` مباشرة عند اختبار الحفظ المشترك.

## النشر العام
1. أنشئ خدمة Node.js على استضافة موثوقة تدعم **قرصًا دائمًا** وHTTPS (أو قاعدة بيانات مُدارة بعد تطوير موصل لها).
2. ارفع مجلد المشروع، واجعل أمر التشغيل `npm start`.
3. عيّن متغير البيئة `ADMIN_PASSWORD` من لوحة أسرار الاستضافة، ولا تضعه في الكود أو Git. عيّن `NODE_ENV=production` و`DATA_DIR` لمسار القرص الدائم.
4. اربط نطاقًا رسميًا بعد موافقة الجهة التعليمية، واختبر الدخول من HTTPS.
5. احتفظ بنسخ احتياطية مشفرة من ملف قاعدة البيانات، وقيّد الوصول إليها. لا تستخدم تخزينًا مؤقتًا يزول عند إعادة التشغيل.

## حدود النسخة ومراجعة ما قبل الإطلاق
- تتطلب مراجعة أمنية فعلية، اختبار ضغط، سياسة خصوصية، مدة احتفاظ بالبيانات، موافقات أولياء الأمور، وضوابط ضد إساءة الاستخدام قبل استقبال مشاركات طلاب حقيقيين.
- الجلسات محفوظة في ذاكرة عملية واحدة؛ يلزم مخزن جلسات دائم أو هوية مؤسسية عند التوسع لأكثر من نسخة خادم.
- الصور والفيديوهات الحالية روابط أو مواد توضيحية؛ لم تُنشأ مكتبة وسائط رسمية معتمدة بعد.
- يجب إبقاء ملفات الإجازات المرضية خارج هذا الموقع حتى اعتماد مسار آمن مخصص وصلاحيات محددة.
- عند تشغيل `NODE_ENV=production` يجب أن يكون الموقع خلف HTTPS لأن كوكي الجلسة `Secure`.
- بعض الاستضافات لا توفر تخزينًا دائمًا أو تدعم `node:sqlite`؛ تحقق من ذلك قبل اختيارها.
